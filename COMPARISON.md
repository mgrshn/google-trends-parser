# Exploding Topics vs наш сервис — конкурентный анализ

*Составлено: июль 2026. Цены и цифры конкурента — на момент анализа, требуют перепроверки перед принятием решений.*

---

## 1. Что такое Exploding Topics и какую задачу он решает

**Exploding Topics** (explodingtopics.com) — сервис раннего обнаружения трендов. Его продукт — ответ на вопрос *«что станет большим, пока оно маленькое»*.

Ценность не в данных как таковых, а во **времени**: кто узнал о тренде первым, получает дешёвый трафик, дешёвую закупку и отсутствие конкурентов.

### Кто платит и за что

| Аудитория | Задача |
|-----------|--------|
| Контент-маркетологи, SEO | Написать про тему до конкурентов → навсегда занять топ выдачи |
| E-commerce, Amazon-продавцы | Закупить растущий товар до пика спроса и цен |
| Предприниматели, инди-хакеры | Каталог растущих ниш как источник идей «что построить» |
| Инвесторы | Ранние сигналы о новых категориях и стартапах |
| Продакты, стратеги | «Куда движется рынок» для решений и отчётов |

### Почему платят, если Google Trends бесплатный

1. **Google Trends требует знать ключ заранее** — Exploding Topics сам приносит темы, о которых пользователь не догадался бы спросить. Это ядро продукта (discovery, а не lookup).
2. **Курация** — алгоритм + человек отсеяли шум и однодневки, повесили лейблы.
3. **Упаковка** — готовая лента «тренды недели в твоей категории» вместо самостоятельного ресёрча.

Продают **сэкономленное время ресёрча + шанс быть ранним**. Тарифы порядка $39–249/мес.

## 2. Место в Semrush

- Основан в 2019 Брайаном Дином (Brian Dean, Backlinko — известная фигура в SEO) и Джошем Ховартом.
- В 2022 Semrush купил Backlinko, в **2024 — Exploding Topics**.
- Semrush — один из двух крупнейших SEO-игроков мира (наряду с Ahrefs).

**Что это даёт Exploding Topics:**
- Абсолютные объёмы поиска («74K/mo»), база 26.6 млрд ключей, ranking difficulty, CPC — всё из инфраструктуры Semrush. Из Google Trends такое получить нельзя (там только относительные 0–100).

**Что это даёт Semrush:**
- Бесплатные тренды и keyword tool работают воронкой: приводят аудиторию, которой продают подписку Semrush (на страницах инструментов — сплошные call-to-action «start free trial»).

**Вывод для нас:** соревноваться с их объёмами поиска в лоб = соревноваться с базой Semrush, накопленной годами. Соревноваться в discovery и realtime — можно: там размер Semrush решающего преимущества не даёт.

## 3. Откуда берут данные

Подтверждённые источники (по их документации и обзорам):

| Источник | Что снимают |
|----------|-------------|
| Google Trends | Динамика поискового интереса |
| Semrush (владелец) | Абсолютные объёмы, difficulty, CPC — база 26.6B ключей |
| TikTok | Хэштеги, тренды коротких видео |
| Reddit | Рост обсуждений и упоминаний на форумах |
| Facebook и др. соцсети | Упоминания |
| Spotify | Подкасты — упоминания тем в выпусках |
| Amazon | Товарные тренды, рост покупок |
| Новостные сайты | Рост упоминаний в медиа |

Маркетинговое «1,000,000+ источников» — это краулинг перечисленного выше.

**Пайплайн:** сбор сигналов отовсюду → NLP выделяет темы → ML отделяет долгосрочный рост от однодневных всплесков → человеческая курация каталога.

**Логика мультиисточниковости:** тренд сначала виден в соцсетях (TikTok/Reddit), через недели — в поиске (Google Trends), ещё позже — в покупках (Amazon). Каждый источник — «сенсор» на своей стадии жизни тренда. Чем больше сенсоров, тем раньше обнаружение.

## 4. Полный функционал Exploding Topics

### Discovery (ядро продукта)
- **Trends Database** — курируемый каталог тысяч трендов с фильтрами: категория (~30 штук), темп роста, объём поиска, временной горизонт (от 3 месяцев до 15 лет)
- **Статусы трендов** — Exploding / Regular / Peaked (алгоритм + ручная курация)
- **Meta Trends** — группировка связанных тем в крупные движения
- **Trending startups / products** — растущие компании и товары

### Lookup
- **Keyword tool** (tools.explodingtopics.com) — объём поиска, difficulty, related keywords по базе Semrush. Обновление ~раз в месяц, ключ должен уже быть в базе. По сути — витрина Semrush.

### Аналитика
- Рост в % за разные периоды
- **Прогноз траектории** (forecast) — предсказание, куда пойдёт тренд

### Доставка
- **Projects / Tracking** — отслеживание выбранных тем
- **Алерты** — уведомления, когда тема начинает «взрываться»
- **Еженедельная рассылка** (бесплатная — главный канал привлечения)
- **Отчёты** по категориям
- **API** — только в дорогом тарифе
- **Web-UI** с графиками и каталогом

### Операционный слой
- Человеческая курация: алгоритм находит кандидатов, редакторы отсеивают мусор

## 5. Что умеем мы (текущее состояние парсера)

### API
- `GET /trends` — интерес во времени по любому ключу: 9 периодов (1h/4h/1d/7d/1m/3m/12m/5y/all) + произвольный диапазон дат, любая страна или весь мир, 5 движков (web/youtube/images/news/shopping), категории Google
- `GET /trends/batch` — до 20 ключей × N стран за запрос
- `GET /trends/compare` — 2–5 ключей в общей шкале (значения сравнимы между собой)
- `GET /status`, `GET /health` — мониторинг
- Auth по API-ключу, Swagger-документация

### Инфраструктура
- Кеш в PostgreSQL с TTL по типу диапазона (от 1 минуты для часовых данных до 30 дней для 5y)
- Партиционированное хранилище точек + retention policy (авточистка)
- Очередь Redis: дедупликация заданий, ретраи, dead queue
- Пул прокси в БД: CLI-управление, горячая перезагрузка без рестарта
- Производительность: **~1M запросов к Google/сутки с одного прокси-аккаунта**, масштабирование добавлением аккаунтов, success rate 100% на рабочей конфигурации
- Docker Compose, миграции, полная воспроизводимость развёртывания

## 7. Наши преимущества уже сейчас

1. **Realtime по любому ключу.** У них база, обновляемая батчами; свежий ключ (вчерашний бренд, мем) они не покажут, пока он не попадёт в базу. Мы скрейпим в момент запроса — свежесть от 1 минуты.
2. **Гранулярность до минут** (1h/4h/1d) — у них месячные объёмы и дневные/недельные графики.
3. **Любая страна на запрос** — у них фиксированные региональные базы.
4. **5 движков** — YouTube/News/Images/Shopping тренды, у их keyword tool только веб-поиск.
5. **API-first** — у них API только в самом дорогом тарифе.
6. **Себестоимость** — один прокси-аккаунт даёт 1M запросов/день; их данные — аренда чужой базы.
7. **Свои данные** — мы не зависим от тарифов и правил стороннего поставщика.

## 8. Итог: закрывает ли наш парсер задачу «сделать как у них»

**Нет, не 1в1 — но фундамент правильный.** Мы построили промышленный «сенсор» для главного источника (Google Trends) и универсальную инфраструктуру (очередь/воркеры/кеш/прокси), на которой остальные слои строятся без переделок.

**Принципиальная разница режимов:** у нас lookup («как ищут ключ X?»), их ядро — discovery («какие темы взлетают?»). Их lookup при этом — витрина покупной базы Semrush, а не конкурент нашему realtime.

### Дорожная карта до функционального аналога

| Этап | Что появляется | Срок |
|------|----------------|------|
| 1. Related queries + метрики роста + статусы | discovery по Google Trends, лейблы «exploding» | 1–2 недели |
| 2. Регулярный рескан словаря + алерты | «замечаем тренд раньше», уведомления | +1–2 недели |
| 3. База трендов с фильтрами + Reddit/TikTok | browsable каталог, мультиисточниковость | +месяц |
| 4. Объёмы поиска (покупные), UI, прогнозы | паритет по метрикам и упаковке | по мере необходимости |

**Ориентир: ~2 месяца разработки** до функционального аналога без UI и покупных объёмов. Фронтенд и человеческая курация — отдельные решения.

### Стратегические ниши, где мы сильнее

- **Realtime trends API** — продаваемо уже сейчас (у конкурента этого нет в принципе)
- **Discovery по узкой нише клиента** — их каталог общий, мы можем сканировать конкретную вертикаль глубже
